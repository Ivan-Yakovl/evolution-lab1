# Лабораторная работа №1
## Многомерная оптимизация функции Михалевича генетическим алгоритмом

**Вариант:** 10  
**Функция:** Михалевича, f(x) = −Σ sin(xᵢ)·sin²ᵐ(i·xᵢ²/π), m=10  
**Размерность:** d = 5 + (10 mod 6) = 9  
**Область:** [0, π]⁹  
**Группа:** Б24-517, № в группе 28

## Постановка задачи

Требуется найти приближённое глобально оптимальное решение:

```
min f(x), x ∈ [0, π]⁹
```

где f(x) — функция Михалевича с параметром m=10.

## Параметры алгоритма

| Параметр | Значение |
|---|---|
| Размер популяции | 100 |
| Число поколений | 300 |
| Селекция | турнирная, k=3 |
| Кроссовер | SBX (Simulated Binary Crossover), η=15, p=0.9 |
| Мутация | гауссова, σ=0.15·(u−l), p=0.2 |
| Элитизм | 2 особи |
| Обработка границ | отражение (clip) |
| Seed | 42 (серия 42..61) |

## Дополнительное задание

Реализованы:
- SBX-кроссовер (Simulated Binary Crossover) для вещественных векторов
- Гауссова мутация с отражением от границ области поиска
- Сравнение со случайным поиском при равном бюджете вычислений

## Обоснование выбора операторов

**SBX-кроссовер** выбран потому, что он хорошо работает с вещественным представлением и позволяет контролировать распределение потомков относительно родителей через параметр η.

**Гауссова мутация** обеспечивает локальный поиск вокруг текущих решений, а отражение от границ предотвращает выход за допустимую область.

**Турнирная селекция** с k=3 обеспечивает баланс между селективным давлением и разнообразием популяции.

## Выводы

1. Генетический алгоритм значительно превосходит случайный поиск при равном бюджете вычислений
2. Увеличение размера популяции улучшает сходимость, но требует больше вычислений на поколение
3. Слишком низкая вероятность мутации (0.05) приводит к преждевременной сходимости
4. Слишком высокая вероятность мутации (0.50) дестабилизирует поиск
